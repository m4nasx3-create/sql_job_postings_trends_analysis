### 1. Top Paying Business Analyst Roles and Skills 
To identify the highest-paying roles, I filtered Business analyst positions by average yearly salary and location, focusing on remote jobs. This query highlights the high paying opportunities in the field.
```sql
with top_paying_jobs as (
SELECT
    job_id,
    company_dim.name as company_name,
    job_title,
    salary_year_avg
    from job_postings_fact
    LEFT JOIN company_dim ON company_dim.company_id = job_postings_fact.company_id
    WHERE
    job_title_short = 'Business Analyst' AND
    job_location like 'Anywhere' AND
    salary_year_avg is not NULL
    ORDER BY
    salary_year_avg deSC
    limit 10
)
SELECT 
    top_paying_jobs.*,
    skills_dim.skills
FROM top_paying_jobs
inner join skills_job_dim on 
    skills_job_dim.job_id= top_paying_jobs.job_id
inner join skills_dim on 
    skills_dim.skill_id = skills_job_dim.skill_id
order BY
    salary_year_avg DESC
```
Key Skill Insights:
- **The Core Foundation:** SQL and Python are the undisputed leaders, each appearing in 5 of the top job postings. They form the baseline technical requirement for high-paying data roles.
- **Data Visualization & Spreadsheets:** Excel and Tableau are the next most critical skills, each requested in 4 different roles, highlighting the continued importance of data presentation and traditional spreadsheet analysis.
- **Specialized BI & Stats:** Looker, R, and SAS form a secondary tier of specialized skills, each appearing twice.
- **Niche & High-Value Skills:** Interestingly, while mentioned only once, the skill Chef was associated with the highest average salary ($220,000) in this specific sample. Cloud platforms like GCP and BigQuery also make appearances.

### 2. In-Demand Skills for Business Analysts
this query helped me identify the skills most frequently requested in job postings, directing focus to areas with high demand.
```sql
select 
  skills,
  count(skills_job_dim.job_id) as demand_count
from 
  job_postings_fact
INNER JOIN skills_job_dim on
  skills_job_dim.job_id = job_postings_fact.job_id
INNER JOIN skills_dim on
  skills_dim.skill_id = skills_job_dim.skill_id
where
  job_title_short = 'Business Analyst' AND
  job_work_from_home = true
group by
  skills
order by
  demand_count desc
limit 5;
  ```
Key breakdown:
- **Foundational Skills Dominate:** SQL and Excel are the core market prerequisites for business analysts, firmly leading overall employer demand.
- **Visualization Outpaces Programming:** Business Intelligence tools designed for data storytelling, specifically Tableau and Power BI, are prioritized over advanced programming languages like Python.

### 3. Top Paying Skills for Business Analysts
To identify the most financially rewarding skills for Business Analysts, this query calculates the average salary associated with each skill in the dataset.
```sql

SELECT 
skills,
round(AVG(salary_year_avg),2) as avg_salary
from 
    job_postings_fact
inner JOIN skills_job_dim on 
    skills_job_dim.job_id = job_postings_fact.job_id
inner JOIN skills_dim on 
    skills_dim.skill_id = skills_job_dim.skill_id
where 
    salary_year_avg is not null AND
    job_title_short = 'Business Analyst'
   -- AND job_work_from_home = true
GROUP BY
    skills
order by 
    avg_salary desc
limit 10
```
Here is the breakdown of the highest-paying Business Analyst skills in 3 key trends based on your query results:

- **DevOps & Automation Premium:** Infrastructure and automation skills (like Chef) are exceptionally rare and command the highest salaries.
- **Cloud & Big Data Expertise:** Top-tier roles require navigating modern data pipelines and cloud platforms (Phoenix, BigQuery, Snowflake).
- **Data Science > Standard BI:** Advanced programming for statistical modeling (Python, R) out-earns traditional Business Intelligence tools.

### 4. Most Optimal Skills for Business Analysts: Demand vs. Salary
This query is used to find the optimal solution to find out the 
skills in high demand and with high average salary for business analytics jobs. this targets the jobs that give good job security as well as financial benefits.


```sql
SELECT
    sd.skill_id,
    sd.skills,
    COUNT(sjd.job_id) AS demand_count,
    ROUND(AVG(jpf.salary_year_avg)) AS avg_salary
FROM job_postings_fact AS jpf
INNER JOIN skills_job_dim AS sjd
    ON sjd.job_id = jpf.job_id
INNER JOIN skills_dim AS sd
    ON sd.skill_id = sjd.skill_id
WHERE
    jpf.job_title_short = 'Business Analyst'
    AND jpf.salary_year_avg IS NOT NULL
    -- AND jpf.job_work_from_home = TRUE
GROUP BY
    sd.skill_id, sd.skills
HAVING
    COUNT(sjd.job_id) > 10
ORDER BY
    demand_count DESC,
    avg_salary DESC
LIMIT 25;
```
Key Insights from the analysis:

- **Core analytical skills:** SQL, Excel, and Tableau dominate demand, making them foundational skills for Business Analysts.
- **Programming premium:** Python and R are associated with higher salaries, highlighting the value of advanced analytical capabilities.
- **Specialized skill advantage:** Cloud and data infrastructure technologies such as Snowflake and AWS offer strong earning potential despite lower demand.
- **Strategic skill development:** Combining SQL, Python, and BI tools provides a balance between market demand and earning potential, while specialized technologies offer opportunities for career progression.
